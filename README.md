### Serial command assignments

#### Dabble gamepad mapping:
Up       | U | 
Down     | D | 
Left     | L | 
Right    | R | 
Square   | Q | 
Circle   | C | 
Cross    | X | Scoop down
Triangle | T | Scoop up
Start    | A | Stop all motors
Select   | B | Toggle line following

#### Terminal value input:
Character| _ | Imitate gamepad input
Digit    | V | Move scoop to position
